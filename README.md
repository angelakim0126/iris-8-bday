# Iris's 8th Birthday Pokémon Party

A fan-made, non-commercial birthday invitation for a private family party.

- `index.html` is the invitation (hosted with GitHub Pages).
- `config.js` holds the Google Apps Script web app URL that stores RSVPs in the host's Google Sheet.
